⑧ 歩行者の回避を尤度で読む（Dryad 交錯歩行）

条件付きNFで歩行者の"いつもの動き"を学習。回避（人手ラベル）が起きる文脈を、較正確率・反実（混雑）・前触れ・幾何量との対決で多角的に読む。

0.036校正ECE
+6.3pp反実ΔP(混雑→回避)
0.73前方ギャップAUROC
0.56サプライズAUROC

1. このデータは何か

Dryad「交錯歩行の回避軌跡」（Wuhan Univ. of Technology, 40人, 10m×10m, 俯瞰25fps, PeTrack頭部追跡）。赤帽(RP)が対角に横断し、黄帽(YP)の往復流を縫って歩く。刺激＝密度3水準（低/中/高＝Exp1/2/3, 各3反復＝9試行）。RPの各時刻に回避戦略が人手ラベル（NWS通常 / A加速 / D減速 / T迂回 / S停止）。10Hzに再標本化し、RP 90人・10,841ステップを対象（YPは近傍文脈に使用）。座標cm→m。

2. 何を・どう学習したか

条件付き Normalizing Flow（zuko NSF＋GRU履歴）で p(次の自己中心移動 dfwd,dlat | 履歴・近傍k人の相対配置・局所密度・密度水準・個人ID) を学習。サプライズ = −log p。前触れ用には通常歩行(NWS)だけで学習した"正常モデル"を別に用意（eHMI流：正常で学習→逸脱を検知）。学習/検証はRP個人単位で分割（密度層別、リーク防止）。

3. 結果

A1 生成・較正：held-out で Flow NLL 0.39（Gaussian 2.73 / 等速 3.03 を大きく凌駕）、ECE=0.036で確率は信用できる。

A3 反実（混雑）：同じ局所文脈で密度水準を低→高に差し替えると回避確率が平均 +6.3pp上がり、|ΔP|>5pp が42.5%。生の回避率も密度で 0.25→0.34→0.41 と単調増。＝混雑が回避を因果的に押し上げることを校正確率で言える。

A2/A4 前触れ対決：ここが重要な発見。回避の0.6秒前を当てるAUROCは、サプライズ0.56に対し前方ギャップ(−front_gap)0.73・最近傍距離0.62の方が高い。つまりこの"日常的な回避"は幾何量でよく予測でき、尤度サプライズはほとんど先行しない（lead time 検出されず）。

4. 図の見方

校正＝点が対角線に乗るほど確率が正直。反実ΔP＝0付近は密度で変わらない場面、正の裾は混雑が回避を強める場面。ベースライン棒＝0.5が当てずっぽう、前方ギャップが最も高い。前触れ曲線＝縦線t=0が回避開始。開始前に橙線が青(NWS基準)を越えれば先行検知だが、ここでは越えない。

5. 解釈と意味・使い道

この応用の収穫は二つで、片方は"効き"、片方は"効かない"を正直に示す点にある。
効く＝因果：較正確率＋反実で「混雑は回避を+6.3pp押し上げる」と数字で言える。歩行空間設計・混雑管理・群集流の評価に使える。
効かない＝前触れ：eHMIの危険（急な回避）ではサプライズが先行したのに、Dryadの"合理的な回避"は尤度サプライズでは予知しにくく、前方ギャップの縮小という幾何量が最良の先行指標だった。これは失敗ではなく境界の発見で、「サプライズは"異常な反射的機動"の前触れであって、"当然の予期的回避"の前触れではない」という仮説を生む。この仮説は姉妹ページ ⑨ 密群衆(Lyon) と ⑩ データ間転移 で検証する。
