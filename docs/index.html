KAN-NF

人間にまつわるデータ × Normalizing Flow — プロジェクト統括

条件付き Normalizing Flow で log p(行動 | 文脈) を学習し、尤度そのものを製品にする探索。 NFが光るのは「低次元・連続・多峰の条件付き密度で、サプライズ・エントロピー・較正・生成が価値になる」場面。 主な使い方は3つ： サプライズ = −log p（異常/忘却/ミス） 迷い = 予測エントロピー（分岐/意思決定） 反実生成（本来どう動くべきか）

指標の読み方：NLL（負の対数尤度）は低いほどデータによく当てはまる／AUC・AUROCは0.5が偶然・1.0が完全／相関 ρ・rは±1が完全・0が無関係。各カードの数値は「勝ち負け」ではなく密度モデルの特性の差として読んでください。
